QUICKکارهای سریع

وصل کردن هوش مصنوعیکلید، آدرس MCP و راهنمای Claude، ChatGPT و بقیه
root@server 
یک دستور بنویس و «اجرا» را بزن.
دستورها با دسترسی root روی سرور اجرا می‌شوند.

      CONNECTاتصال هوش مصنوعی

      کلید (دسترسی root کامل)
      آدرس MCP (برای کانکتورها)
      این سرور در حالت HTTPS مستقیم (self-signed) است. Claude Code بدون مشکل وصل می‌شود، ولی کانکتورهای وب (claude.ai و ChatGPT) گواهی عمومی می‌خواهند. برای آن‌ها روی سرور بزن: fatllm mode caddy
      Claude Code پیشنهادی
      1. در تنظیمات محیط ابری، Network access را روی Full بگذار.
      2. متغیر FATLLM_KEY را برابر کلید بگذار (یا فقط «پیام آماده» را در چت بفرست).
      3. جلسه را روی ریپوی FATLLM باز کن؛ بدون پرسیدن کار می‌کند.
      claude.ai
      1. Settings ← Connectors ← Add custom connector
      2. آدرس MCP بالا را بده.
      3. در تنظیمات همان کانکتور، ابزارها را روی Always allow بگذار.
      ChatGPT
      1. Settings ← Connectors ← Advanced ← Developer mode را روشن کن.
      2. یک کانکتور تازه بساز و آدرس MCP را بده.
      3. ChatGPT ممکن است برای کارهای تغییردهنده تأیید بخواهد؛ این تنظیم خودش است.
      سایر ایجنت‌ها
      1. هر ایجنتی که MCP می‌شناسد: آدرس MCP.
      2. هر ایجنتی که دستور یا درخواست وب می‌زند: خود کلید؛ راهنمای کامل داخلش است.
      کلید را فقط جایی بگذار که به آن اعتماد داری. اگر لو رفت، پایین «کلید تازه» را بزن.
